# TripSplit

This is the complete TripSplit Expo/React Native project.

## Run
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npx expo start`.

## GitHub
Upload the entire contents of this folder to one GitHub repository.

## App flow
Trips -> Create Trip -> Add Expense -> Balances -> Simplest Settlement.

The app runs immediately with demo/local data. Supabase configuration and database schema are included for persistent cloud data.
